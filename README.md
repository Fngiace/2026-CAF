# 2026-CAF｜鑽石模型引導實戰

CAF（Certified Agile Facilitator）認證培訓第二組五分鐘試教的延伸教學網頁。

**線上閱讀：** https://fngiace.github.io/2026-CAF/

## 內容

1. 你以為的會議 vs. 真實的會議
2. 全景圖：發散區、震盪區、收斂區（互動圖）
3. 發散區：產生清單、開放討論、暫停評斷
4. 從震盪到收斂：建立共同理解，接著清單排序、彙整主題、行使判斷
5. 真實案例：DevFest 網美牆要不要放講者照片？
6. 小測驗
7. 帶回團隊的三句話

鑽石模型（Diamond of Participatory Decision-Making）出自 Sam Kaner 等人所著《Facilitator's Guide to Participatory Decision-Making》。

整個網站就是一個 `index.html`，不需要建置步驟。
